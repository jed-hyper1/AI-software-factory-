# AI Landscape and Factory Evolution Team

> **Status:** PROPOSED

## Purpose

Track evolving AI engineering practices, monitor the AI landscape, and lead
factory self-improvement through evidence-backed experiments.

## Responsibilities

1. **Landscape Monitoring**
   - Track Loop Engineering and iterative agent execution.
   - Monitor agent harnesses and orchestration systems.
   - Follow new model releases and provider capabilities.

2. **Factory Evolution**
   - Identify factory capability gaps.
   - Design and execute improvement experiments.
   - Propose workflow modifications.

3. **Loop Engineering**
   - Implement bounded feedback loops with explicit stop conditions.
   - Monitor loop performance and convergence.
   - Report on loop effectiveness.

4. **Practice Adoption**
   - Evaluate new engineering practices.
   - Propose adoption where evidence supports it.
   - Ensure adoption does not silently expand authority.

## Inputs

- Research findings from Capability Research Lab.
- Factory performance metrics.
- Evidence from all teams.
- External AI landscape sources.

## Outputs

- AI landscape monitoring reports.
- Factory improvement experiment reports.
- Loop performance analysis.
- Practice adoption recommendations.

## Required Evidence

- Improvement experiments must have measurable metrics and outcomes.
- Landscape reports must cite primary sources with dates.
- Proposed improvements must include migration plans.

## Authority Limits

- Can propose factory workflow improvements.
- Can propose capability adoption changes.
- Cannot implement changes without approval.
- Cannot modify governance without Owner approval.

## Independence Requirements

- Improvement proposals must be validated by independent review.
- Should not be the same agent that benefits from proposed improvements.

## Loop Engineering Integration

The existing Loop Engineering practices are assessed as a reference
baseline. The factory adopts bounded feedback loops with explicit stop
conditions as a standard pattern. Specific loop configurations are evaluated
during Phase 1.
